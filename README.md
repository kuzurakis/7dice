# Семь костей (7dice) — desktop JavaFX

Коротко: настольная игра по правилам из ТЗ. Проект — Java 17 + JavaFX + Gradle.

Features (initial):
- 2–5 игроков (локально, на одном компьютере)
- Поле 4×4 — 7×7 в зависимости от игроков
- Структура для правил движения, конфликтов, скоринга
- Сохранение/загрузка игры в JSON (Gson)
- RU/EN локализация
- Unit tests (JUnit 5), Mockito

Запуск:
- ./gradlew run

Что будет дальше:
- Реализация всех правил движения, захватов, подсчёта очков
- Полный UI/UX: подсказки шагов, подсветка конфликтов
- Покрытие тестами 90%+ для ключевой логики

Acceptance:
- Можно начать новую партию (2–5 игроков)
- Ходы ограничены (бросок / убрать+бросок / пас)
- Конфликты работают по правилам
- Итоговый подсчёт + расшифровка комбинаций
- Сохранение/загрузка + seed
